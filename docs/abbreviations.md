# FastBasic abbreviations (atari-int)

Generated by `tools/abbrevs.py` from the FastBasic grammar files. "Shortest" is what a minimizer writes; any longer prefix ending in a dot works too. "Rule" is the grammar rule the word appears in.

Two statements have a symbol that beats any abbreviation: `?` is PRINT and `@` is EXEC (`@P` calls PROC P). A word with no dot in the Shortest column has no abbreviation: write it out (`INC`, `DO`, `END`).
